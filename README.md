# Maghreb Chat

A Moroccan-inspired social messaging app concept built with Next.js and TypeScript. It includes a modern chat interface with contacts, groups, profile/account information, post feed, and a live multi-timezone digital clock.

## Features

- Contact list sidebar
- Group section
- Profile/account panel
- Social post feed
- Live digital clock for multiple time zones
- Warm Moroccan-inspired color palette
- Responsive layout for desktop and mobile

## Tech Stack

- Next.js
- React
- TypeScript
- CSS Modules / custom CSS

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Run the development server:

```bash
npm run dev
```

3. Open the app in your browser:

```bash
http://localhost:3000
```

## Build for Production

```bash
npm run build
```

## Start Production Server

```bash
npm run start
```

## Notes

This is a front-end app prototype designed to resemble a modern chat application with a Moroccan aesthetic. It is ready for extension with authentication, real-time messaging, and database-backed data.
